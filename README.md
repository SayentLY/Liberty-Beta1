# Liberty Coffee — готовий сайт

Статичний односторінковий сайт-презентація для Liberty Coffee (Кучаків, Київська область).

## Структура

- `index.html` — основна сторінка
- `styles.css` — адаптивний дизайн
- `script.js` — мобільне меню та перегляд фото
- `assets/` — фотографії з наданих матеріалів

## Що потрібно змінити перед продажем власнику

1. Замінити блок меню на фактичні позиції та ціни.
2. Додати реальний номер телефону замість демонстраційного.
3. Графік роботи: щодня 07:30–22:00.
4. Instagram уже підключений: https://www.instagram.com/liberty__coffee2023
5. Google Maps уже підключено до кнопок маршруту.
6. За бажанням додати QR-код, форму замовлення/бронювання та реальні відгуки.
5. Замінити Google Maps-пошук на точне посилання на картку закладу.

## Як запустити

Просто відкрийте `index.html` у браузері — сайт працює без сервера.

## Як опублікувати

Проєкт можна завантажити на Vercel, Cloudflare Pages або GitHub Pages. Для власного домену його можна підключити після публікації.

## Важливо

Фото в `assets/` походять із матеріалів, наданих замовником для створення демо. Перед комерційним використанням переконайтеся, що у вас є право використовувати ці фотографії та логотип/бренд.
